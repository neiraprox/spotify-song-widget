# Spotify Song Widget

Widget web que muestra la canción que el usuario está reproduciendo en Spotify.

## Configuración rápida

1. Crea una app en https://developer.spotify.com/dashboard/
2. Copia el Client ID.
3. Abre `index.html`.
4. Reemplaza `PON_TU_CLIENT_ID_AQUI` por tu Client ID.
5. Publica el proyecto en GitHub Pages.
6. En Spotify Developer Dashboard agrega como Redirect URI la URL exacta de tu página, por ejemplo:
   `https://TU-USUARIO.github.io/spotify-song-widget/`

Importante: el Redirect URI debe coincidir exactamente con el que usa la aplicación.
